How much room each instruction file gets

repo-bootstrap caps every instruction file it writes. Even the largest cap, 300 lines for a SKILL.md, is 60% of the 500 lines the Agent Skills spec recommends.

A SKILL.md gets the most room because it can hand detail off

Anything that would push a SKILL.md past 300 lines moves into references/, which the agent reads only when a step needs it. AGENTS.md is read at the start of every session, so it stays at half that.

The smallest files add to AGENTS.md rather than repeat it

copilot-instructions.md carries only Copilot-specific notes, and a skill that runs only when called as /name is a single task. Both get 40 lines.
